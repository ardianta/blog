## 🛠 Command Reference for AI Agents

When executing shell commands, strictly use the following:

- **Run Development Server**:
  ```bash
  hugo server -D
  ```
  *(Serves site locally with draft articles enabled at `http://localhost:1313/`)*

- **Build Production Site (Audit & Test)**:
  ```bash
  hugo --gc --minify
  ```

- **Create New Post Stub**:
  ```bash
  hugo new content/post/nama-artikel.md
  ```

- **Create New Project Stub**:
  ```bash
  hugo new content/project/nama-projek.md
  ```

## ✍️ Content & Writing Standards

### 1. Frontmatter Format
All posts MUST use **YAML** frontmatter format delimited by `---`:

```yaml
---
title: "Judul Artikel yang Jelas dan Menarik"
slug: judul-artikel-kebab-case
date: 2026-07-26T12:00:00+08:00
draft: false
type: post
tags:
    - Tutorial
    - Hugo
    - Linux
image: "/img/judul-artikel/cover.webp"
description: "Ringkasan singkat artikel dalam 1-2 kalimat untuk meta description dan preview."
---
```

### 2. Frontmatter Field Rules
- `title`: Capitalize correctly, use clean title without unnecessary symbols.
- `slug`: Lowercase, hyphen-separated (kebab-case), matching the filename without `.md`.
- `date`: Standard ISO-8601 string including timezone offset (e.g., `+08:00`).
- `draft`: Set to `true` while drafting, set to `false` when ready for publication.
- `type`: `post` for blog articles, `project` for portfolio showcase items.
- `tags`: Array of relevant categories/topics (Title Case).
- `image`: Path to cover image located in `static/img/...` (referenced in markdown as `/img/...`).
- `description`: 1-2 sentences summarizing the article (critical for SEO).

### 3. Writing Style Guidelines
- **Language**: Indonesian (Bahasa Indonesia).
- **Tone**: Casual, informative, structured, and helpful. Use "saya" for personal voice.
- **Formatting**:
  - Use Heading 2 (`##`) for main sections, Heading 3 (`###`) for sub-sections. Never use H1 (`#`) in post body (Hugo renders `title` as H1).
  - Code blocks MUST specify the language (e.g. ` ```bash `, ` ```javascript `, ` ```yaml `).
  - Always use WebP images for illustrations and store them under `static/img/<slug>/`.
  - Include descriptive `alt` text for all images (`![Deskripsi Gambar](/img/...)`).

## ⚠️ Important Rules for AI Agents

1. **Do not modify `public/` directory manually**: The `public/` folder is generated by Hugo.
2. **Preserve existing post history**: Do not edit dates or slugs of published articles without explicit user request, as it breaks permalinks (`/:slug/`).
3. **Verify Hugo build before completing tasks**: Run `hugo --gc` to ensure no rendering errors occur.
4. **Use relative image URLs**: Always start image paths with `/img/...` which resolves to `static/img/...`.
